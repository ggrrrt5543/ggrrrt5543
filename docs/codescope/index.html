    ЧТО ПРОИСХОДИТ ВНУТРИ

    Не магия.
    Конкретные проверки.

    CodeScope собирает результаты анализаторов в один формат. Отдельно показывает, что проверено, а какой инструмент не установлен.

    PythonAST / Ruff / Bandit / Pyright
    C++Tree-sitter / G++ / Cppcheck
    C#Tree-sitter / Roslyn (.NET 8)
    JavaTree-sitter / javac (JDK 17+)

    Без компилятора остаётся разбор синтаксиса. Это частичная проверка, а не успешная полная.

    НАЧАТЬ ЛОКАЛЬНО

    Скачай. Запусти. Проверь.

    Python 3.10+ и Node.js 20+ для Pyright. Компиляторы подключаются отдельно. Docker-образ содержит полный набор инструментов.

    Инструкция установки ↗
    git clone https://github.com/ggrrrt5543/codescope.git
cd codescope
python -m venv .venv
# Активируй .venv для своей ОС
python -m pip install -e .
codescope serve
